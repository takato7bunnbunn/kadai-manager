# kadai-manager

大学の課題の締切を管理するコマンドラインツールです。
課題を登録すると締切が近い順に並べ、残り時間と緊急度を表示します。

## 特徴

- 締切が近い順に自動で並べ替え
- 「あと3日」「あと5時間」のように残り時間を表示
- 締切が近い課題に印を表示（`!` 3日以内 / `!!` 24時間以内 / `!!!` 期限切れ）
- 日付は `2026-11-20` でも `11/20` でも入力可能（年を省略すると直近の日付になる）
- 標準ライブラリのみで動作（追加のインストール不要）

## 必要なもの

- Python 3.10 以上

## 使い方

```bash
# 課題を追加（時刻を省略すると 23:59）
python kadai.py add "物理学実験レポート 第3回" 11/12 --time 17:00 --subject 物理実験
python kadai.py add "線形代数 演習5" 11/14 --subject 線形代数

# 締切が近い順に表示
python kadai.py list

# 完了にする / 削除する（番号は list で確認）
python kadai.py done 2
python kadai.py delete 2

# 完了した課題も含めて表示
python kadai.py list --all
```

### 表示例

```
番号  締切              残り        科目          課題
------------------------------------------------------------------
1     11/12(木) 17:00   あと1日     物理実験      物理学実験レポート 第3回 !
2     11/14(土) 23:59   あと3日     線形代数      線形代数 演習5
3     11/25(水) 23:59   あと14日                  プログラミング課題
```

## データの保存先

課題は `kadai.py` と同じフォルダの `kadai.json` に保存されます（Git の管理対象外）。
